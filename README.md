# Portafolio académico inicial

Ejercicio de HTML y CSS que conserva una primera aproximación a la estructura de un portafolio.

## Ejecución

Abre index.html en un navegador. El portafolio profesional actualizado se mantiene en bastiiiuuu.github.io.

## Alcance

Conservar los créditos de recursos externos. No incluir credenciales ni datos privados en nuevas publicaciones. La propiedad del repositorio no atribuye automáticamente la autoría de todos sus recursos.
